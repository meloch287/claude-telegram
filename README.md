# AI Bot

**Claude Code и GPT Codex в одном Telegram-боте — с мини-аппом и рабочей зоной в браузере**

Пишешь задачу в Telegram — агент работает в своей папке: читает и правит файлы, запускает команды, ходит в интернет, присылает результат. Переключаешься между Claude и GPT одной кнопкой, а продолжить можно в браузере с того же места.

## Что умеет

**Два движка в одном чате**
- **Claude Code** (Agent SDK) — Opus, Sonnet, Fable; глубина размышления, режимы работы от «спрашивать на всё» до «без подтверждений».
- **GPT Codex** — модели GPT по подписке ChatGPT; список моделей подтягивается сам из каталога Codex — новые модели появляются без правок кода.
- Переключатель движка в Telegram и мини-аппе. У каждого движка своя история диалогов, `/resume` — вернуться к любому.

**Агент, который делает, а не только отвечает**
- Отдельная папка на каждый диалог, файлы приходят в чат.
- Изоляция: у каждого пользователя свой Linux-пользователь для Claude и свой Docker-контейнер для GPT (только чтение корня, без лишних прав).
- Весь трафик к моделям — через защищённый прокси: упал туннель — бот встаёт, а не ходит мимо.
- **Оркестрация агентами**: большие задачи модель раскладывает на субагентов и перепроверяет. Готовые сценарии — `/workflows`: `/review`, `/plan`, `/audit`, `/fix-until-green`, `/compare`, `/explain`, `/fact-check`, `/server-check`, `/karta`.

**Мини-апп в Telegram**
- Модель, глубина размышления, режим работы, лимиты подписки Claude (пятичасовое и недельное окно) и расход GPT.
- Поиск по чатам и файлам обоих движков, задачи, кот-компаньон и «Мой мир» за работу в боте.
- Нативный вид Telegram, светлая и тёмная тема.

**Рабочая зона в браузере (bb)**
- Те же диалоги, что в Telegram: вкладки **Claude | GPT** над списком диалогов.
- Claude-диалог из браузера ведёт тот же движок, что и Telegram — одна история, продолжай где удобно. Пока диалог отвечает в одном месте, второе ждёт.
- Сменил движок посреди диалога — новый получает скрытую сводку того, что сделал прежний.

**Админка**
- Пользователи, приглашения, лимиты токенов и диалогов, статистика подписок.
- Выключатели **GPT / Claude**: закрытый движок недоступен всем, кроме владельца, — бот отвечает «временно ограничен» в Telegram, браузере и консультациях.

**Сам себя обновляет**
- Каждую ночь бот проверяет новую версию Claude Code: собирает её в стороне, прогоняет тесты, подменяет только когда нет задач, при сбое откатывается и пишет владельцу отчёт.
- Про новые версии Codex и bb приходит уведомление: их обновление — пересборка контейнеров, её запускают осознанно.

## Как устроено

```
Telegram ──► ai-bot (Node, dist/index.js) ── Claude Agent SDK ─► Claude Code (под uid пользователя)
               │  мини-апп :8788                  │
               │                                  └─ data/claude-bb.sock ◄── мост для браузера
               ▼
          ai-gpt-backend (gpt/main.mjs) ── Docker-контейнер пользователя ─► Codex CLI, bb
               │  шлюз рабочей зоны :8792 (bb в браузере)
               └  вход 172.30.0.1:8790 (модели GPT, команда ИИ, мост Claude)

Все внешние запросы ─► ai-bot-proxy (Xray, fail-closed nftables)
```

| Путь | Что там |
|---|---|
| `src/` | бот Claude: Telegram, мини-апп, сессии, лимиты, мост `bb-bridge.ts`, выключатели `engine-access.ts` |
| `gpt/` | бэкенд GPT: Codex, шлюз рабочей зоны, команда ИИ, зеркала диалогов, каталог моделей `gpt-models.mjs` |
| `src/miniapp/public/` | мини-апп (собирается копированием в `dist/miniapp/public/`) |
| `claude-workflows/` | готовые воркфлоу Claude Code (раскладываются каждому в `~/.claude/workflows`) |
| `scripts/` | автообновление, перевод и патчи фронта bb (`bb-engine/`), сжатие ассетов |
| `test/`, `gpt/*.test.mjs` | тесты |
| `КАРТА.md` | шпаргалка по серверу: службы, выкатка, откат, логи |

## Запуск и проверка

```sh
npm ci
npm run build          # tsc + сборка мини-аппа
npm test               # node --test gpt/*.test.mjs
```

Настройки — в `.env` (пример: `.env.example`): токен бота, ключ шифрования, папки данных и рабочих зон, прокси. Секреты в репозиторий не попадают.

На сервере бот работает как службы systemd: `ai-bot` (Claude, Telegram, мини-апп), `ai-gpt-backend` (GPT и рабочая зона), `ai-bot-proxy` (туннель), таймер `ai-bot-autoupdate` (ночное обновление). Выкатка идёт релизами с проверкой хэшей, ожиданием тишины и автоматическим откатом — подробности в `КАРТА.md`.

```sh
systemctl status ai-bot ai-gpt-backend
journalctl -u ai-bot -u ai-gpt-backend -f
curl -fsS http://127.0.0.1:8788/healthz
```
