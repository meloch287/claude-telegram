## Мини-апп: дизайн и выкатка статики
- Дизайн-система: `src/miniapp/public/ui.css` — цвета из темы Telegram, один акцент режима (GPT зелёный, Claude глиняный), строки-ячейки, сегмент-переключатель, шторка, анимации. Главная — `modes.*`, «Чаты и файлы» — `library.*`; статистика (`style.css`) и админка (`chats.css`) подтянуты к тем же токенам блоком в конце файла.
- Уровень `ultracode` скрыт: в мини-аппе — `hiddenLevels` в `modes.js`, в рабочей зоне — фильтр в `scripts/patch-bb-reasoning.py`.
- Статика мини-аппа читается с диска (no-store + etag): выкатка = замена файлов в `src/` и `dist/miniapp/public`. `ai-bot` ради этого НЕ перезапускать — через него идут чаты с Claude.
- Рабочая зона (bb, `/opt/ai-bot/bb-ru-dist`): ассеты immutable на год — менять имена файлов по цепочке до `index.html` (суффикс `-reasoningN`). `ai-gpt-backend` держит `index.html` в памяти → после смены ссылки перезапустить его, только если в `gpt_jobs` нет `running`.
- Релиз мини-аппа: `/opt/ai-bot/releases/ui-redesign-20261009` — `python3 deploy.py --check`, `python3 deploy.py`; откат: `sh rollback.sh`.

- Русский перевод дополняется словарём `scripts/bb-ru-dict.json` (literals — точные строки интерфейса, code — точечные правки) через `scripts/patch-bb-ru.py <frontend> <dict>`; изменённые модули получают суффикс `-ru4` по цепочке до index.html. После пересборки bb из исходников — прогнать снова.
