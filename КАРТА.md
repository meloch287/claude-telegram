# КАРТА — claude-telegram

Телеграм-бот, через который Саня разговаривает с Claude Code с телефона.
Это тот самый бот, в котором идёт переписка: **перезапуск бота обрывает
текущую задачу** и шлёт «бот перезапустился». Выкатывать — с отложенным
перезапуском и самоотчётом (см. ниже), не посреди разговора.

## Где живёт

- Сервер 103.88.241.202 (root), папка `/opt/claude-telegram` — она же git-репозиторий.
- Локальная копия для правок: `workspaces/1057399602/default/claude-telegram`
  (это та же папка, смонтированная в контейнер как `/app/workspaces`).
- Контейнеры (docker compose, сервисы `bot`, `proxy`, `botapi`):
  `claude-telegram` — сам бот, `claude-proxy` — xray-пул выходов (порты
  10801–10805, нужна страна DE), `telegram-bot-api` — локальный Bot API для
  файлов больше 20 МБ.
- Бот запускается как `npx tsx src/index.ts` — прямо из исходников, без dist.
  Проверять «докатилось ли» надо по `/app/src/...`, а не по `/app/dist`.

## Настройки и секреты

- `/opt/claude-telegram/.env` — всё окружение. Токен бота лежит в
  **`BOT_TOKEN`** (не `TELEGRAM_BOT_TOKEN`). Владелец — первый id в
  `ALLOWED_USER_IDS`. `MINIAPP_URL` — адрес мини-аппа.
- `/opt/claude-telegram/claude-home` — домашняя папка Claude внутри
  контейнера: oauth-сессия, настройки, навыки. API-ключа нет, вход по подписке.
- База `data/` (sqlite): пользователи, расход, коты, лимиты.

## Как выкатывать

```
cd /opt/claude-telegram
docker compose build bot
# перезапуск обрывает разговор — делаем отложенно и с отчётом в чат:
systemd-run --unit=claude-roll --collect /bin/bash /root/roll2.sh
```

`roll2.sh` ждёт 20 с, пересоздаёт контейнер (`docker compose up -d
--force-recreate bot`), дожидается healthy и шлёт в чат 1057399602 отчёт
через `BOT_TOKEN`. Откат: `git checkout -- .` и та же процедура.

Правки в `package.json` требуют `npm install --package-lock-only` (через
`docker run node:24-slim`), иначе `npm ci` в сборке падает.

## Проверка

- Типы: `npx tsc -p tsconfig.json --noEmit` (локально есть node_modules).
- Тесты: `npm test` (tsx --test test/logic.test.ts).
- Мини-апп глазами: `PORT=8788 npx tsx scripts/serve-miniapp.ts`, открыть
  `/?demo=1`. Локальный Chromium не запускается (нет libglib), скриншоты
  снимаются на сервере Холистики (`/root/demo`, Playwright рабочий):
  залить `src/miniapp/public` в `/root/demo/mp/public`, поднять
  `python3 -m http.server 8799`, прогнать `/root/demo/shot-mp.mjs`.
- Здоровье: `docker inspect claude-telegram --format '{{.State.Health.Status}}'`,
  `/healthz` на порту мини-аппа.
- Логи: `docker logs --since 1h claude-telegram`.

## Модели

Список кнопок в `src/bot/keyboards.ts` (`MODELS`). Любую модель можно
поставить и без кнопки: `/model claude-fable-5-1`. Новые модели требуют
свежего `@anthropic-ai/claude-agent-sdk` — если API отвечает «version X or
newer is required», поднимать версию в `package.json` и пересобирать.

## Мини-апп

`src/miniapp/server.ts` отдаёт статику из `src/miniapp/public` и
`/api/profile` по подписанным initData. Две вкладки: «Кот» (статистика,
лимиты, коты, достижения) и «Мой город» (`world.js`) — остров четырёх
кошачьих народов в духе WorldBox. Сид острова — хеш user_id, считается на
сервере (`worldSeed`), поэтому у каждого свой и всегда один и тот же.
Мир целиком (ландшафт, деревья, дома, коты, корабли, эры) лежит снимком в
localStorage под ключом `world:v<версия>:<seed>`; смена `SAVE_VERSION` в
`world.js` пересоздаёт остров у всех. Панель в духе WorldBox: категории
(Коты, Природа, Ландшафт, Бедствия, Прочее), кисти протяжкой, зум, рука.
Значки — свой пиксельный набор в `icons.js` (12×12, SVG на лету), эмодзи в
панели нет. Остров стартует пустым, с нулём котов, как новый мир в WorldBox: народ
появляется там, где бог провёл первого кота, дома коты строят сами (один на
трёх котов), рождения зависят от домов. Статистика человека влияет только
на плодовитость. Эры: Начало → Средневековье → Будущее — по настоящему возрасту
острова и числу домов, или инструментом «Эра»; меняются дома (хижина →
двухэтажный → башня) и корабли (парусник → летучая лодка).
Территории народов (4 клетки от домов и столицы, спорные — кому ближе)
рисуются отдельным слоем с границей, подписи с численностью — HTML поверх
карты в процентах, чтобы переживали зум. Настройки за шестерёнкой в шапке:
подсветка, подписи, пауза, скорость 1/2/4×, «начать заново». Таймер «живёт
N д» — настоящее время с создания острова (`born` в снимке).
У каждого кота имя (слоги по народу), у каждой деревни — название от
основателя (Мурзиград, Элилесье, Грохрог, Дурингорн); подписи на карте — по
деревням с их численностью, отключаются отдельно от подсветки территорий.
Экономика (`COST`): у деревни склад брёвен и камня. Кот-дровосек рубит
дерево минуту (`CHOP_TICKS`) и приносит 5 брёвен, хижина стоит 10;
улучшение дома под эру — 10 брёвен и 10 камня (камень долбят в горах);
верфь — 20 брёвен на берегу, без неё кораблей нет. Уровень у каждого дома
свой (`h.lvl`), эра народа — только потолок. Лес отрастает (`regrow`).
Склад в подписи не показывается (только в title по нажатию). Вьюпорт на 1× без ограничения по высоте,
чтобы карта влезала целиком; `.wb-body` держит оверлеи относительно карты.
У народа несколько деревень (`villages`): разросшаяся отселяет троих котов
на новое место, территория тянется от каждого дома и растёт с их числом.
Войны: соседи по границе начинают сами (орки чаще), либо инструмент «Война»
в «Коты»; каждый четвёртый кот — воин (лук в Начале, меч в Средневековье,
бластер в Будущем), дома от попаданий загораются, через 100 с — мир со
счётом потерь. Союзы: мирные соседи (особенно с общим врагом) заключают
союз на 4 минуты и вступают в чужие войны друг за друга — так на одного
нападают двое. Над столицами воюющих на карте мечи, у союзников —
рукопожатие. Пять боевых сцен: выпад с дугой удара, свалка мечников с
пылью, отброс с красной вспышкой, залп стрел по дуге, луч бластера;
погибший кот уходит призраком. Карт пять (`MAPS`: остров, архипелаг,
континент, нагорье, озёрный край), у каждой своё сохранение
(`world:v<версия>:<seed>:<map>`), выбор — в настройках с миниатюрами,
текущая карта в `world:map:<seed>`. Остров живёт в фоне: при переключении вкладки симуляция не
останавливается, а при открытии после паузы догоняет пропущенное время
(`catchUp`: до трёх минут тик за тиком, дальше по дням крупными мазками).
Деньги «по API» и число отклонённых инструментов из интерфейса убраны
(и из `/stats`, и из строки «Готово» после запроса) — по просьбе владельца.
`telegram-web-app.js` лежит в `public/` и отдаётся с нашего домена: telegram.org
с телефона в России без VPN не открывается, и мини-апп висел на его загрузке.
Обновлять — скачивать через прокси изнутри контейнера
(`docker exec claude-telegram curl -x http://claude-proxy:10802 …`), с хоста
telegram.org недоступен.
Статика отдаётся с `cache-control: no-store`: WebView Telegram иначе держит
старую панель часами, и после выкатки «ничего не поменялось».

## Внешние зависимости и что отваливается

- Telegram Bot API — ходит напрямую с сервера; при обрыве бот теперь
  повторяет отправку (1с, 3с, 7с). Раньше ответ терялся молча.
- Anthropic — только через `claude-proxy` (страна DE). Если все выходы
  пула мертвы, бот молчит; смотреть `docker logs claude-proxy`.
- Подписка Claude: лимиты 5 часов и 7 дней видны в мини-аппе.
